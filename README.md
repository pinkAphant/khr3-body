# @khr3/body

First-person body for khr3: `@pinkaphant/ecctrl` `<Ecctrl>` used as designed, plus a camera, a view model and held-item sockets.

**Spec stage.** Only the SI constants are built and tested. Read [SPEC.md](./SPEC.md).

```ts
import { BODY_SI, bodyRestCenterY, bodyEyeOffsetY } from "@khr3/body";
bodyRestCenterY(); // 0.95 m
bodyEyeOffsetY();  // 0.67 m
```
